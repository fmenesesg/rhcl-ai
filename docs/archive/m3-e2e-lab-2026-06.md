## Lab validation (sandbox cluster-d6rb2)

- GateForge stack via `podman-compose` + `.env` (3scale Admin API, OpenShift API read-only).
- **E2E `auto`:** seed → export → visualize → offline import → analyze (4 lab products + pre-existing tenant products).
- **E2E `fixture`:** smoke import + analyze (2 products).
- **FAQ warm-up:** 10/10 cached with `AI_ENDPOINT=https://maas-rhdp.apps.maas.redhatworkshops.io/v1`, `AI_MODEL=deepseek-r1-distill-qwen-14b`, `AI_TIMEOUT=600s`.

### Technical fixes discovered during lab

| Issue | Fix |
|-------|-----|
| jq `false // true` treats `incomplete: false` as true | Explicit boolean check in E2E script |
| Live `backend_usages.json` is top-level array | `ThreeScaleExportParser` |
| Product YAML `kind: List` not parsed | `extractProductSpec()` |
| Incidental `oidc_configuration.json` on API-key products | Auth inferred from proxy flags |
| FAQ upstream timeouts | `AI_TIMEOUT=600s`, warm-up retries, summary context (no full namespace list) |
